# Docker

Este directorio alojará Dockerfiles, configuración de Nginx, healthchecks y
scripts de entrada. El `docker-compose.yml` final estará en la raíz.

La topología aprobada está descrita en
[`docs/operations.md`](../docs/operations.md). No se incluye en la Fase 1 una
composición ficticia que no pueda construirse o verificarse.
